# Job Market Intelligence

A Python and MySQL based job market analysis project with an interactive Streamlit dashboard.

## Project Overview

This project analyzes job market data to identify trends in:

- Job demand by job title
- Job opportunities by location
- Salary ranges and average salaries
- Experience-level requirements
- Company-wise job distribution
- Job type distribution
- Required skills

The analyzed data is presented through an interactive web dashboard built with Streamlit.

## Technologies Used

- Python
- MySQL
- Streamlit
- Pandas
- Matplotlib
- MySQL Connector/Python

## Key Features

- Interactive job search and filtering
- Filter jobs by job title, location, and experience
- View salary information
- View job details and required skills
- Analyze job demand by location
- Compare average salaries by job title
- Compare minimum and maximum salary ranges
